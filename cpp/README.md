# Linkbar (C++20 port)

Порт оригинального Delphi-приложения Linkbar 1.6.9 на C++20.
Используются только WinAPI, GDI и системный GDI+ (`gdiplus.dll`) — без сторонних
библиотек отрисовки и без VCL. Все окна, меню, Jump List, диалоги и элементы
управления созданы вручную через Win32 API.

## Сборка

Требуется MSVC с поддержкой C++20 и Windows SDK.

```powershell
cd cpp
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

Готовый бинарник: `cpp/build/Release/linkbar.exe` (~550 КБ, статическая CRT).
Сборка проверена на `/W4`: **0 предупреждений, 0 ошибок**.
Минимальная версия Windows — Vista (проверка ОС при запуске, как в оригинале).

## Структура

| Файл | Назначение |
|---|---|
| `src/Constants.h/.cpp` | перечисления, константы, значения по умолчанию и INI-ключи (порядковые значения совпадают с Delphi) |
| `src/IniFile.h/.cpp` | in-memory INI-парсер, совместимый с `TMemIniFile` (включая `$`-шестнадцатеричные цвета) |
| `src/StringUtil.*` | UTF-8 ↔ UTF-16, регистронезависимые сравнения, FNV-1a |
| `src/DibBitmap.*` | RAII-обёртка 32-bpp top-down DIB section (аналог `THBitmap`) |
| `src/Os.*` | версия ОС через `RtlGetVersion`, пути, запуск процессов, аргументы |
| `src/Common.*` | геометрия, DPI, UIPI, системные меню, безопасное удаление пунктов меню |
| `src/DarkTheme.*` | недокументированная тёмная тема uxtheme (ordinal 133/135) |
| `src/Localization.*` | локализация из `Locales\*.ini` с fallback для `%s` |
| `src/Theme.*` | цвета панели задач, отрисовка кнопок/разделителей/фона, DWM-политики, glass-текст |
| `src/Hint.*` | нативный tooltip-контрол (`TTM_*`) |
| `src/DirectoryWatch.*` | `ReadDirectoryChangesW` с маршаллингом в UI-поток |
| `src/Shell.*` | PIDL, иконки `IShellItemImageFactory`, UAC-щит, контекстные меню, Drag&Drop, Shell-уведомления, рабочие области мониторов |
| `src/Items.*` | элементы панели, файл `list`, раскладка, `StrCmpLogicalW`, иконки |
| `src/AppBar.*` | AppBar, `ABM_SETAUTOHIDEBAREX`, TaskbarCreated |
| `src/BarWindow.*` | главное окно: layered-рендеринг, ввод, автоскрытие, перетаскивание, меню |
| `src/Dialogs.*` | настройки (5 вкладок, все параметры), создание панели, переименование, SpinEdit, HotKey-редактор |
| `src/ColorPicker.*` | градиентный выбор цвета: поле насыщенности/яркости, полоса оттенка, альфа, HEX |
| `src/Jumplist.*` | чтение Jump List (Classic Shell port + `IApplicationDocumentLists` fallback), задачи, закрепление/удаление, собственное всплывающее окно |
| `src/main.cpp` | `-d`, `-l`, `-f`, `-n`, `-ca`, мультипроцессный запуск панелей |

## Реализованные возможности

* Все параметры оригинала: позиция, выравнивание, порядок, размер иконок, отступы,
  положение/ширина/смещение текста, свечение, цвета, прозрачность (Opaque/Transparent/Glass),
  AeroGlass, стиль Light/Dark/Accent, разделители, автоскрытие, задержка, горячая клавиша,
  угловые прозрачные зоны, подсказки, Jump List.
* Точная геометрия `UpdateLines`, размеры кнопок для всех положений текста, DPI-база 96.
* `UpdateLayeredWindow` с корректным source-offset по краю, «камуфляж» `$01000000`,
  прозрачные углы в скрытом состоянии.
* AppBar, автоскрытие (hover/left/right click), горячая клавиша, drag&drop (внутренний и OLE),
  контекстные меню, переименование, удаление, сортировка, несколько панелей.
* Редактор настроек с реальными вкладками, SpinEdit с UpDown, редактором горячей клавиши,
  диалогом выбора цвета для фона и текста.
* Jump List: чтение задач/закреплённых/недавних/частых элементов, выполнение,
  закрепление, открепление, удаление, tooltip, клавиатурная навигация,
  fallback на системное контекстное меню, если у приложения нет списка.
* Локализация, `-d/-l/-f/-n/-ca`, восстановление панелей после перезапуска Explorer.

## Совместимость профилей

INI-ключи, значения по умолчанию, диапазоны и порядковые значения перечислений
совпадают с Delphi-версией, поэтому существующие `.lbr`-профили читаются без конвертации.

Исходная Delphi-версия и её ресурсы (`src/`, `components/`, `exe/`, `ico/`) оставлены без изменений.
